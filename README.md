# DaevaEye Meter

DPS-метр и анализатор боёв для **AION 2** (ПК, глобальный клиент).

**[⬇ Скачать последнюю версию](https://github.com/dmitrii-maksimov/DaevaEye-Meter/releases/latest/download/DaevaEye.Meter_0.1.0_x64-setup.exe)** · [все релизы](https://github.com/dmitrii-maksimov/DaevaEye-Meter/releases)

## Что умеет
- DPS-метр пати: урон, доли, крит, тыл, скиллы, бафы, смерти; мини-окно поверх игры с настраиваемой прозрачностью.
- Шанс победы на боссов по составу пати, с учётом лимитов времени; отчёты по боям и сравнение с прошлыми.
- Дроп, кинары, шмот, камни маны, титулы, профессии, доски Дэваниона.
- PvP, окно «Асмодиане» рядом, компас скрытых кубов, группы из окна подбора, таймеры мировых боссов.
- Новости и техработы из официальных объявлений.
- Автообновление: новая версия скачивается сама, ставится по кнопке или при выходе.

## Как работает
Пассивно читает сетевые пакеты сервера через Npcap. Не трогает процесс игры, не читает память клиента, ничего не отправляет на сервер игры.

## Установка
1. Установите [Npcap](https://npcap.com/#download) (галочка «WinPcap API-compatible Mode»).
2. Скачайте и запустите установщик. Данные хранятся в `%LOCALAPPDATA%\DaevaEye Meter Data`.
